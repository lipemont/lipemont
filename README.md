## How I Build

Every project has to solve a problem, even a small one. Trying to understand the problem before jumping into the code is what helps me build better solutions.

For me, the small details matter. A project can work technically and still provide a poor experience, so I try to think about both sides: how it works and how it feels to use.

___Aesthetics should serve usability.___
